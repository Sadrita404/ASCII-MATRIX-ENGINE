### ASCII art is text art created with ASCII, a protocol established by the American National Standards Institute (ANSI), So I Made something similar to that where it will give the image live through the web cam directly.

---

## Inspo:

For this Project I take my referance like the ASCII art that I recently saw on reddit and I want to make something related to it .

---

## Why I built it:
I want to build something on top of this  ASCII protocol filter so I make it from scrtch and I like it how it is turned out and I will add more filter in the future .

## Features

* Can take picture with ASCII text
* We can Mirror our Image .
* We also have an own text as the ASCII Filter 
* We can save our Picture as .png format

---

## To run it locally 
* 1) Fork the repo 
* 2) Open the file in your code editor (VS Code )
* 3) Open The Terminal 
* 4) Write - open index.html (Mac) , start index.html (Windows) , xdg-open index.html (Linux)
